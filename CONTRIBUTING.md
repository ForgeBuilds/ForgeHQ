# Contributing

Thanks for your interest in contributing to Forge HQ.

## How to contribute

1. Fork the repository and create a feature branch from `main`.
2. Install dependencies: `npm install`.
3. Run the dev server: `npm run dev`.
4. Make your changes, then run `npm run lint` and `npm run build` to verify.
5. Open a pull request with a clear description of what changed and why.

## Guidelines

* Keep changes focused and small; one logical change per PR.
* Follow the existing code style (TypeScript, ESLint config in `eslint.config.js`).
* Don't commit secrets or `.env` files.
* Be respectful — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Reporting issues

Open an issue on GitHub with steps to reproduce, expected vs. actual behavior,
and your environment (OS, browser, Node version).
